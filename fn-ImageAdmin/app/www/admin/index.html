API 服务与开发者中心

温馨提示：如需在第三方客户端（如 PicGo）中使用 API，请确保已在“展示设置”中开启“外部访问”并配置正确端口。

私有密钥管理

用途/名称 Token (API Key) 限流速率 状态 操作

接口与参数说明

接口类型 请求地址 (Endpoint) 限流策略 说明与用途
公共随机接口
(Public API)		 GET /api/v1/public/random 20次/分钟/IP 无需验证。适合用于博客随机头图、开源项目挂载。严格防止滥用。
私有随机接口
(Private API)		 GET /api/v1/private/random 跟随密钥设定 需要在请求头中携带 Token 验证。调用额度高，适合开发者集成到自己的 App 或后台业务中。
私有上传接口
(Private Upload)		 POST /api/v1/private/upload 跟随密钥设定 支持本地二进制上传或网络资源抓取。支持自定义描述、标签等丰富元数据。

私有上传参数 (POST Parameters)

参数名 类型 必填 说明
mode String 是 上传模式：local (本地文件) 或 remote (网络链接)
file / url - 是 local 模式下对应文件字段 file；remote 模式下对应 JSON 字段 url
category_id Int 是 目标分类的 ID
title String 否 图片标题
description String 否 图片详细描述内容
tags Array/Str 否 标签。JSON 数组或逗号分隔字符串

通用查询参数 (Common Query Parameters)

参数名 类型 必填 说明
category_id Int 否 指定分类的 ID。默认为 0（表示全部分类中随机）。
format String 否 若设定为 image，则放弃返回 JSON，直接 302 重定向到真实的图片地址。非常适合直接写在 <img src="..."> 标签或 CSS 背景图中。

私有接口请求示例

方式一：Header 传参（推荐，更安全）

curl -X GET "http://127.0.0.1:8080/api/v1/private/random?format=image" \
-H "Authorization: Bearer sk_xxxxxxxxxxxxxxxx"

方式二：URL 传参（便捷，适合 img 标签直接嵌入）

<img src="http://127.0.0.1:8080/api/v1/private/random?format=image&token=sk_xxxxxxxxxxxxxxxx">

私有上传接口示例 (Private Upload Examples)

场景一：远程 URL 抓取 (JSON 方式)

curl -X POST "http://127.0.0.1:8080/api/v1/private/upload" \
-H "Authorization: Bearer sk_your_token" \
-H "Content-Type: application/json" \
-d '{
  "mode": "remote",
  "url": "https://example.com/image.jpg",
  "category_id": 1,
  "title": "抓取标题",
  "description": "这是通过 API 自动生成的详细描述内容",
  "tags": ["自动化", "采集"]
}'

场景二：本地文件上传 (Form-Data 方式)

curl -X POST "http://127.0.0.1:8080/api/v1/private/upload" \
-H "Authorization: Bearer sk_your_token" \
-F "mode=local" \
-F "file=@/path/to/your/image.jpg" \
-F "category_id=1" \
-F "description=本地推送描述"

Python 自动化脚本示例 (requests 库)

import requests

url = "http://127.0.0.1:8080/api/v1/private/upload"
headers = {"Authorization": "Bearer sk_your_token"}
data = {
    "mode": "remote",
    "url": "https://example.com/img.jpg",
    "category_id": 1,
    "description": "这是从第三方采集到的内容描述..."
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
