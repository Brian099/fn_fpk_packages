💡 使用说明与最佳实践
  • SNI 多域名复用：HTTP/HTTPS 协议支持在同一个端口（如 80 或 443）上绑定多条不同域名的规则，系统将自动基于 SNI 与 Host 头部路由分发。
  • 系统证书匹配：如需启用 HTTPS，请先在飞牛 OS「系统设置 → 证书管理」中添加 SSL 证书，系统将按精确域名 > 泛域名 > 通配回退自动寻找最佳证书。
  • 纯端口数据转发：TCP/UDP 模式专为数据库、SSH、游戏服务端等非网页协议设计，此模式下域名绑定与 HTTP 高级功能将自动隐藏。
  • 热加载即时生效：规则添加、修改或删除后由引擎实时热重载，无需重新启动应用服务。
