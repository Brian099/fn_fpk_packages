快速入门

登录后台

在浏览器中访问 http://你的服务器地址:端口/admin/，输入管理密码即可登录。

默认密码：admin123，可通过环境变量 ADMIN_PASSWORD 修改。首次登录后建议立即修改密码。

界面概览

后台采用左侧导航栏 + 右侧内容区的布局。左侧导航栏按功能模块分组，点击即可切换页面。顶部版本号显示当前服务端版本。

  • 仪表盘 — 系统概览，显示频道、设备、流等统计数据
  • 内容管理 — 频道、分组、M3U 源的核心管理
  • 客户端授权 — 设备管理、套餐管理、访问日志
  • 系统设置 — 全局设置、系统更新、主备同步、系统日志

仪表盘

仪表盘是后台首页，展示系统关键运行指标：

  • 总频道数 / 在线频道 — 频道库总量及当前可播放的频道数量
  • 活跃流 — 当前正在被客户端拉取的代理流数量
  • 已授权设备 / 待审批 — 已通过审批的设备数量和等待审批的设备数量
  • 在线设备 — 最近 5 分钟内有活跃连接的设备数量
  • M3U/TXT 源 — 已配置的外部节目源数量
  • 总播放时长 — 所有设备累计播放时长
  • 运行时长 / 内存占用 — 服务端运行时间和当前内存使用情况

下方"最近访问"表格显示设备的最新操作记录，点击"刷新"可更新数据。

频道管理

频道管理是后台最核心的功能模块，支持对频道进行增删改查、排序、健康检查等操作。

添加频道

  1. 点击右上角 「+ 添加频道」 按钮
  2. 填写频道名称、选择分组、输入流地址（支持 HLS、TS、FLV、RTMP、RTSP、MP4、DASH 等格式）
  3. 设置内容类型：直播 (Live) 或 点播 (VOD)，留空自动推断
  4. 配置直连模式、复用流、Logo URL、EPG 频道 ID 等可选参数
  5. 点击「保存」即可
提示：流地址支持网络 URL 和本地文件路径（需在全局设置中开启"允许本地文件路径"）。
内容类型说明：直播模式下客户端不支持暂停、进度拖拽等操作；点播模式则支持暂停、seek 进度条、音轨/字幕切换。如果选错类型，客户端相关功能可能异常。建议不确定时留空让系统自动推断。

直连模式

开启后，客户端直接连接原始流地址播放，不经过服务器中转代理。适用于客户端能直接访问的源站地址。

复用流 (Multiplex)

开启后，当多个客户端播放同一频道时，服务器只从源站拉取一路流，然后分发给所有客户端，大幅节省带宽。

注意：复用流需要关闭直连模式，且流格式必须是代理可转发的格式（如 TS、HLS）。

频道排序

在频道列表表头点击 「移动」 列，可拖拽调整频道顺序。调整完成后点击右上角出现的橙色 「保存排序」 按钮即可生效。

健康检查

点击 「健康检查」 按钮，设置预期完成时间，系统将逐一探测所有频道是否可播放。探测采用平滑滚动机制，不会高并发请求源站。

建议：健康检查会占用一定的网络带宽和源站资源，建议在非高峰时段执行，避免影响用户正常观看。

批量操作

勾选多个频道后，点击 「批量操作」 可批量删除频道。

注意：频道删除后不可恢复，请谨慎操作。

搜索与筛选

使用搜索框可按频道名称搜索，使用来源筛选下拉框可过滤特定来源的频道。

分组管理

分组用于对频道进行分类管理，客户端也会按分组展示频道列表。

添加分组

  1. 点击「+ 添加分组」按钮
  2. 填写分组名称、排序值
  3. 可设置该分组下所有频道的默认直连模式、User-Agent、自定义请求头
  4. 支持批量线路复用（需全组频道均支持复用）

分组排序

与频道排序类似，拖拽「移动」列调整顺序后点击「保存排序」。

批量操作

勾选分组后点击「批量操作」可删除分组及其下所有频道（不可恢复）。

M3U 源管理

支持从外部 M3U/TXT 订阅源自动拉取频道和分组数据。

添加源

  1. 点击「+ 添加源」按钮
  2. 填写来源名称、M3U/TXT 文件的 URL
  3. 开启自动同步并设置同步间隔（小时），系统将定时拉取更新
  4. 可设置自定义 User-Agent 和请求头
建议：同步间隔不宜设置过短（建议至少 6 小时以上），频繁请求可能被源站限流或封禁 IP。

粘贴导入

点击「粘贴导入」可手动复制 M3U 内容或上传本地 .m3u/.m3u8/.txt 文件导入。

注意：添加源后，频道和分组会自动创建。删除源不会自动删除已创建的频道和分组，需手动清理。

活跃流

实时查看当前所有正在被代理拉取的流媒体会话。每个条目显示：

  • 会话/设备 — 播放设备的标识
  • 频道 — 正在播放的频道名称
  • 原始 URL — 源站流地址
  • 状态/网速 — 当前连接状态和实时传输速率
  • 启动/活跃时间 — 会话开始时间和最近活跃时间

支持手动断开特定会话，点击「刷新」更新列表。

设备管理

管理所有接入的客户端设备，支持审批、授权、封禁等操作。

设备状态

  • 待审批 — 新设备注册，需管理员手动通过（或开启自动审批）
  • 已授权 — 可正常播放的设备
  • 已拒绝 — 被拒绝的设备
  • 已封禁 — 被封禁的设备，无法连接
  • 已过期 — 授权已过期的设备

审批设备

  1. 在待审批列表中点击设备对应的「通过」按钮
  2. 选择绑定套餐（可选），或手动设置有效期和同时在线数量
  3. 确认通过

批量操作

勾选多个设备后，可批量通过、拒绝、封禁或删除。

注意：封禁或删除操作会立即生效，被封禁设备的 Token 即时失效，客户端将断开连接。批量操作不可撤销。

筛选与搜索

支持按状态筛选，按设备名、IP、ID 搜索。

测试设备：设备列表中标记为"测试机"的设备不受维护模式限制，可在系统维护期间正常使用，便于管理员测试验证。

套餐管理

套餐用于批量管理设备的授权策略，包括有效期、同时在线数量和频道访问权限。

创建套餐

  1. 点击「+ 添加套餐」按钮
  2. 填写套餐名称、有效期（天）、允许同时在线设备数量
  3. 设置价格（可选，仅展示用途）和描述
  4. 选择该套餐可访问的频道分组（可拖拽排序），不勾选则没有任何频道的访问权限
  5. 保存后系统自动生成订阅 Token

订阅链接

套餐支持生成 M3U/TXT 订阅链接，可供第三方播放器（如 VLC、Tivimate）直接导入使用。

前提：需在「全局设置」中开启"外部订阅"功能。订阅链接使用专属鉴权参数，不影响设备 Token 的安全边界。
注意：修改套餐内容（有效期、在线数量、关联分组）后，已绑定该套餐的设备不会自动更新授权，需要重新绑定才能生效。

全局设置

全局设置页面包含多个配置模块，按功能区域分组展示。

服务器授权与网络配置

  • 服务器名称 — 客户端显示的服务器名称（最多 20 个字符，留空则不显示）
  • 自定义服务器外网地址 — 客户端连接使用的地址，留空自动识别
  • 备用服务器地址 — 主地址故障时客户端按顺序尝试连接
  • 授权码 — 客户端连接服务器所需的 Base64 编码信息，可直接复制使用

订阅配置

开启后可在套餐管理页面复制 M3U/TXT 订阅地址，分享给用户导入第三方播放器使用。

频道源配置

开启"允许本地文件路径"后，频道流地址支持 file://、ftp://、webdav:// 等协议。

设备授权配置

  • 自动审批 — 新设备注册时自动通过，可选绑定默认套餐或自定义授权参数
  • 允许同时在线设备数量 — 自动审批时默认值
  • 有效期 — 自动审批时默认有效期（0 = 永不过期）

客户端公告配置

设置系统公告（跑马灯），客户端顶部会滚动显示。可设置自动播报间隔，0 表示仅换台和启动时显示。

EPG 节目源配置

  • EPG 数据源 URL — 支持多个 XMLTV 格式源（每行一个），支持 .xml 和 .gz 格式
  • 自动刷新间隔 — 定时拉取 EPG 数据
  • 全局时差 — 调整 EPG 节目时间偏移
  • 点击「强制拉取 EPG」可立即刷新

台标缓存配置

  • 台标策略 — 本地优先 / 源优先 / 接口优先
  • 台标源库地址 — 配置台标包根目录，自动拼接频道名称拉取
  • 支持缓存已有外链台标、增量拉取、全量覆盖拉取

开机广告/欢迎图配置

支持配置开机时展示的图片或视频广告：

  • 选择图片模式或视频模式
  • 设置最大展示时长和多少秒后允许跳过
注意：不建议填入 m3u8 等直播流地址，会导致开机严重卡顿。

OTA 在线升级配置

配置客户端在线升级：

  • 最新版本号（Version Code）— 客户端版本号小于此值将提示升级
  • 展示版本名（Version Name）— 如 v1.2.0
  • APK 下载地址
  • 更新日志
  • 是否强制更新

FCC 毫秒级换台加速

Fast Channel Change 功能，开启后通过 UDP 组播流实现秒开级别换台。

重要：FCC 需要 Docker 使用 network_mode: host 或 macvlan，并需在路由器中映射 UDP 端口范围。

系统维护模式

开启后，非测试设备连接时将进入全屏维护提示，自动停止播放，便于进行系统维护。

操作提示：修改管理密码后，当前登录会话不会立即失效，重新登录后才需使用新密码。修改服务器地址后，已分发的客户端授权码需要重新复制分发。

主备同步

主备同步功能用于搭建多节点架构，实现数据的热备和负载分担。

主服务器配置

  1. 设置数据拉取授权码（Sync Serve Token），供备机连接使用
  2. 保存后，备机可使用此 Token 拉取主节点数据

备用节点配置

  1. 开启「作为备用边缘节点运行」
  2. 填写主节点通信地址（Master Node URL）
  3. 填写主节点通讯秘钥
  4. 设置自动同步间隔（分钟）
  5. 保存配置即可
注意：「强制立即覆盖拉取」是危险操作，会直接用主节点数据覆盖当前备机数据。

客户端使用说明

以下说明适用于 Android TV / 手机端客户端应用。

连接服务器

  1. 首次打开客户端，进入服务器配置界面
  2. 输入管理员提供的授权码（Base64 编码字符串，可在后台「全局设置」顶部复制）
  3. 客户端自动解析服务器地址和授权信息，完成连接
  4. 连接成功后，自动进入频道列表
提示：如果服务器地址变更，只需重新获取授权码并在客户端中更新即可，无需重新安装应用。

频道导航与换台

  • 频道列表 — 按分组展示，左右键切换分组，上下键选择频道
  • 数字键换台 — 支持遥控器数字键直接输入频道号切换
  • EPG 节目指南 — 在频道列表中可查看当前和后续节目信息（需配置 EPG 数据源）
  • 频道收藏 — 支持将常用频道添加到收藏夹，便于快速访问

直播模式操作

  • OSD 面板 — 按遥控器 OK 键显示，再次按 OK 键暂停/播放（仅点播模式支持暂停）
  • 音量控制 — 遥控器音量键调节
  • 信息显示 — OSD 面板显示当前频道名称、节目信息、时间等
  • OSD 自动隐藏 — 面板显示后 10 秒无操作自动隐藏
说明：直播模式下不支持暂停、快进/快退操作。如需这些功能，频道需设置为点播（VOD）类型。

点播模式操作

  • 暂停/播放 — 按 OK 键切换（OSD 显示时第二次按 OK 触发）
  • 进度拖拽 — 左右方向键控制进度条前后跳转
  • 音轨切换 — 在 OSD 面板中点击「音轨」按钮，选择可用的音频轨道
  • 字幕切换 — 在 OSD 面板中点击「字幕」按钮，选择可用的字幕轨道
  • 进度显示 — OSD 面板显示当前播放进度和总时长
提示：音轨和字幕按钮仅在频道包含多条音轨或至少一条字幕时显示。如果频道只有一条音轨且无字幕，按钮不会出现。

遥控器按键说明

  • OK 键 — 首次按显示 OSD（不暂停），OSD 显示时再次按切换暂停/播放
  • 左/右键 — OSD 按钮聚焦时切换按钮焦点；无按钮聚焦时控制进度条（点播模式）
  • 上/下键 — 频道列表导航
  • 返回键 — 返回频道列表或退出应用
  • 数字键 0-9 — 快速切换频道（输入数字后自动跳转）

客户端设置

  • 画面比例 — 支持 16:9、4:3、拉伸、原始比例等模式
  • 解码方式 — 支持硬件解码和软件解码，播放卡顿时可尝试切换
  • 播放器内核 — 根据频道格式自动选择 ExoPlayer 或 VLC 内核
  • 关于信息 — 查看客户端版本号、服务器信息、设备 ID 等

常见客户端问题

  • 播放卡顿/缓冲 — 尝试切换解码方式（硬解/软解），或检查网络连接质量
  • 无法连接服务器 — 检查授权码是否正确、服务器地址是否可访问、设备是否已被封禁
  • 有声音无画面 — 尝试切换解码方式，或检查频道视频编码格式是否被设备支持
  • 音轨/字幕按钮不显示 — 说明当前频道只有单音轨或无字幕，属于正常现象
  • 设备待审批 — 首次连接需要管理员在后台审批通过，或联系管理员开启自动审批

常见问题

Q: 如何修改管理密码？

在侧边栏底部点击「修改密码」，输入原密码和新密码即可。也可以通过环境变量 ADMIN_PASSWORD 初始化密码。

Q: 客户端如何连接服务器？

在「全局设置」页面顶部，复制服务器授权码（Base64 编码），在客户端中输入即可自动配置连接。

Q: 频道播放不了怎么办？

可以尝试以下排查步骤：

  1. 在频道管理中使用「健康检查」功能探测频道是否可播放
  2. 检查频道流地址是否正确
  3. 尝试关闭直连模式，使用代理播放
  4. 检查是否被源站限制（User-Agent、Referer 等）
  5. 查看系统日志中的错误信息

Q: 如何让客户端自动更新？

在「全局设置」的 OTA 升级配置中设置最新版本号和 APK 下载地址，客户端启动时会自动检测更新。

Q: 设备显示"待审批"怎么办？

在「设备管理」中找到该设备，点击「通过」按钮进行审批。也可以在「全局设置」中开启自动审批，新设备将自动通过。

Q: 订阅链接无法使用？

请检查：

  1. 「全局设置」中是否已开启"外部订阅"功能
  2. 套餐是否已关联了频道分组
  3. 服务器地址配置是否正确（外网可访问）

Q: 如何备份和恢复数据？

主备同步功能可以实现数据的热备。如需手动备份，可以直接备份服务端的数据库文件。
