## 🚀 使用方法

1. 在 [Releases](https://github.com/${{ github.repository }}/releases) 页面下载对应的 `.fpk` 文件。
2. 在飞牛 OS 桌面的 **应用中心** -> **手动安装** 中上传并安装。
